❓ Ajuda

Como funciona

Este site é 100% offline. Você cria o formulário aqui, copia o JSON e cola no Discord usando /form importar.

Tipos de pergunta compatíveis com o bot

  • Curta — uma linha (até 200 caracteres)
  • Longa — parágrafo (até 1000 caracteres)
  • Número — aceita apenas números
  • Usuário / Canal / Cargo — texto com menção

Tipos extras (só no editor)

Sim/Não, Seleção, Múltipla, Data, URL, E-mail — ficam salvos no rascunho, mas não são exportados para o bot atual porque o Discord não suporta nativamente.

Limites do bot

  • Máx. 5 perguntas por formulário
  • Pergunta: até 45 caracteres
  • Placeholder: até 100 caracteres
  • Cor: formato #RRGGBB

Atalhos de teclado

  • Ctrl+S — Salvar
  • Ctrl+Z — Desfazer
  • Ctrl+Shift+Z — Refazer
  • Ctrl+E — Exportar
  • Ctrl+P — Preview
  • Esc — Fechar modal
