📥 Importar formulário

❓ Ajuda

Como funciona

Este site é 100% offline. Você cria aqui, copia o JSON e cola no Discord com /form importar.

Tipos compatíveis

  • Curta — uma linha (até 200)
  • Longa — parágrafo (até 1000)
  • Número
  • Usuário / Canal / Cargo

Limites do bot

  • Máx. 5 perguntas
  • Pergunta: até 45 caracteres
  • Placeholder: até 100 caracteres

Atalhos

  • Ctrl+S — Salvar
  • Ctrl+Z — Desfazer
  • Ctrl+Shift+Z — Refazer
  • Ctrl+E — Exportar
  • Esc — Fechar modal
