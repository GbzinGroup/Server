❓ Ajuda

Como funciona?

Este site cria formulários que o bot do Discord consegue ler. O fluxo é:

  1. Preencha o formulário aqui
  2. Clique em Gerar JSON
  3. Copie o texto e cole no Discord com /form importar
  4. Use /form enviar para publicar

Tipos de pergunta

  • Curta: uma linha (até 200 chars)
  • Longa: parágrafo (até 1000 chars)
  • Número: aceita apenas números
  • Usuário/Canal/Cargo: mostra dica de menção

Limites do Discord

  • Máximo 5 perguntas por formulário
  • Pergunta: até 45 caracteres
  • Placeholder: até 100 caracteres
